党员培训记录管理系统

联网部署指南 — 让所有人通过一个链接共享使用

方案说明：将系统部署到 Render（免费云平台），所有人通过同一个网址访问，数据共享存储在云端数据库中。

方案一：Render 一键部署（推荐）

1注册 GitHub 账号

访问 github.com/signup 注册账号（如已有可跳过）

2上传项目代码到 GitHub
  1. 在 GitHub 上新建一个仓库（如 party-training）
  2. 将本项目的 server 文件夹内容上传到仓库
  3. 同时把 web-app 文件夹也上传到仓库根目录
3注册 Render 账号

访问 render.com，点击 Sign Up，用 GitHub 账号注册

4在 Render 创建 PostgreSQL 数据库
  1. 进入 Render 控制台，点击 New + → PostgreSQL
  2. 名称填 party-training-db
  3. Database 填 party_training
  4. User 自动生成即可
  5. Plan 选 Free
  6. 点击 Create Database
  7. 创建完成后，记下 Internal Database URL（后面用）
5在 Render 创建 Web 服务
  1. 点击 New + → Web Service
  2. 选择刚才上传的 GitHub 仓库
  3. 名称填 party-training-system
  4. Runtime 选 Node
  5. Build Command 填 cd server && npm install
  6. Start Command 填 cd server && node index.js
  7. Plan 选 Free
6配置环境变量

在 Web 服务的 Environment 页面添加：

Key: DATABASE_URL Value: （粘贴第4步的 Internal Database URL）
7部署并获取公网链接
  1. 点击 Create Web Service 开始部署
  2. 等待 2-3 分钟构建完成
  3. 部署成功后，页面顶部会显示公网地址，如：https://party-training-system.onrender.com
  4. 把这个链接发给别人即可使用！
首次访问：服务器首次启动时会自动导入 Excel 初始数据（27个党支部、685名党员、6493条记录），可能需要 1-2 分钟。

方案二：本地运行 + 内网穿透

如果不想部署到云端，可以本地运行后用内网穿透工具让其他人访问：

1双击运行 启动服务器.bat
2下载 cpolar（免费内网穿透工具）
3安装后运行：
cpolar http 8080
4cpolar 会生成一个公网地址，发给其他人即可
注意：本地运行方案需要你的电脑保持开机，关机后其他人无法访问。

常见问题

Q: 数据会丢失吗？

Render 免费层的 PostgreSQL 数据库 90 天后会被清空。如需长期使用，建议定期在"数据管理"页面导出备份。

Q: 免费层有什么限制？

  • Web 服务 15 分钟无访问会自动休眠，再次访问时自动唤醒（约 30 秒）
  • PostgreSQL 免费层 90 天有效期
  • 每月 750 小时免费运行时间

Q: 多人同时编辑会冲突吗？

系统采用"后写入覆盖"策略，最后保存的数据生效。同时查看不会冲突。

Q: 如何更新数据？

直接在网页上操作即可，所有人看到的数据是同步的（刷新页面获取最新数据）。
